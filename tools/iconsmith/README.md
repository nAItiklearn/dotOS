# iconsmith

Renders the bundled glyph DSL (feature/icons/.../glyph/*.kt) to PNG contact sheets for review, and lints centring/size.

    pip install numpy pillow scipy
    python tools/iconsmith/preview.py overview docs/images/icons-line.png
    python tools/iconsmith/preview.py check

See docs/images/icons-line.png and icons-dot.png for the current pack.
