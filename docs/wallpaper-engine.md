# Wallpaper engine

All DotOS wallpapers are generated by code. Nothing is downloaded and no wallpaper image ships in the APK. The engine lives in `feature/wallpaper` and is used by three hosts:

| Host | Where | Notes |
|---|---|---|
| In-launcher layer | `WallpaperLayer` composable, drawn behind the home pager | Full feature set: shader or Canvas, Glass, blur, dim, photo, scroll parallax |
| Settings previews and thumbnails | `WallpaperLayer` with `animate = false` or a low `maxFps` (24 to 30) | Same code path as the launcher |
| System live wallpaper | `DotWallpaperService` | Same shaders and fallbacks; no Glass, no blur, no photo mode (see below) |

## The `DotWallpaper` contract

A wallpaper is a stateless `object` implementing `DotWallpaper` (`engine/DotWallpaper.kt`):

| Member | Meaning |
|---|---|
| `id`, `name` | Stable id (saved in settings and presets) and display name |
| `colorSlots: List<ColorSlot>` | Named colour slots shown as swatches. Every wallpaper must have a `bg` slot; `isLight` (which decides dark or light home content) is derived from its luminance |
| `params: List<WallpaperParam>` | Numeric sliders (`id`, label, `min`, `max`, `default`, optional `step`) |
| `presets: List<WallpaperPreset>` | Named colour and parameter sets. The first one is the default |
| `animated` | `true` by default. `false` means the renderer never schedules frames |
| `shaderSource: String?` | AGSL source for Android 13+, or `null` to always use the fallback |
| `bindUniforms(shader, frame)` | `@RequiresApi(33)`. Sets every uniform for the current frame |
| `DrawScope.drawFallback(frame)` | Canvas implementation for Android 10 to 12, or when the shader fails |

**Both paths must produce the same picture.** The shader path is the reference; the fallback mirrors its maths. The shared helpers in `wallpapers/Noise.kt` exist in both languages with identical arithmetic: `hash11`, `hash21` (sine-free hashes), `grainAt`, `dotCover` in `Agsl.COMMON`, and `hash11`, `hash21`, `smoothstep`, `phase` and `dot` in Kotlin. `Agsl.COMMON` declares no uniforms, so each wallpaper keeps full control of its own uniform set.

### Per-frame input: `WallpaperFrame`

One `WallpaperFrame` per renderer is mutated in place every frame; do not keep references to it. Fields:

| Field | Meaning |
|---|---|
| `time` | Seconds, already multiplied by the user's animation speed; constant when animation is off |
| `width`, `height` | Canvas size in px |
| `scroll` | Home page scroll, 0 (first page) to 1 (last) |
| `tiltX`, `tiltY` | Reserved for gyroscope parallax. Nothing feeds them yet, so they are always 0 |
| `touchX`, `touchY`, `touchAge` | Last touch position (px) and seconds since it. `WallpaperTouch.report` is called from the home gesture handler |
| `battery`, `charging` | Level 0..1 and charging state |
| `hour` | Local hour of day, fractional, refreshed at most once a minute |
| `density` | Display density |
| `cache` | `MutableMap` for renderer-owned precomputed data |
| `color(id)`, `param(id)` | Resolved colour and parameter values |
| `layoutKey()` | Hash of size, params and colours (not time), for rebuilding caches only when needed |

`WallpaperConfig.resolve()` turns the saved config into a `ResolvedWallpaper`: preset lookup (unknown ids fall back to the first preset; unknown wallpaper ids fall back to Atmosphere), colours (preset colour, then user override per slot), parameters (user value, then preset value, then default, clamped to `min..max`).

### Uniform rules

- Declare every uniform the shader reads, and set only uniforms the shader declares. `RuntimeShader.setFloatUniform` on an undeclared name throws; the exception is caught around bind and draw, the wallpaper marks its shader as broken and uses `drawFallback` from then on.
- Colours are declared `layout(color) uniform half4 name;` and set with `shader.setColor(name, color)`.
- `setStandard(frame)` sets the conventional `iResolution` (float2) and `iTime` (float). Wallpapers that need scroll set `iScroll`.
- By convention parameters are `pName` and colours are `cBg`, `cFg`, `cAcc` or `c1..c4`.
- Keep loops bounded and avoid data-dependent array indexing (guidance from [design-reference.md](design-reference.md)); the shader runs once per pixel per frame.
- Keep the program to one full-screen pass. Static film grain is pixel-locked (`hash21(floor(frag))`) so it never shimmers and also dithers gradients against banding.

### Canvas fallback rules

- No allocation per frame. Build lattices, brushes and tiles once into `frame.cache` (for example the 128 by 128 grain tile) and reuse them.
- Dot lattices are sized in "reference dp": `Dots.unit(frame) = min(width, height) / 393`, so the 120 px thumbnails in the picker draw the same picture as the full screen. `Dots.spacing` also enforces a minimum pitch so a full screen never exceeds about 4800 dots.
- Parallax of dot patterns is `Dots.parallaxX/Y` (scroll plus tilt).
- Dots smaller than 0.75 px fade out instead of popping, in both paths (`dotCover`, `dot`).

## Registered wallpapers

`AllWallpapers.list` defines picker order. Unknown ids resolve to Atmosphere.

| Id | Name | Notes |
|---|---|---|
| `atmosphere` (default) | Atmosphere | Four drifting blurred colour lights over a base colour, vignette, static grain, optional time-of-day tint. Uses `hour`. Presets: Paper, Mocha, Midnight, Ember, Frost, Signal Red, Sage |
| `dot_field` | Dot Field | Uniform dot lattice with Gaussian falloff around one accent dot |
| `halftone_orb` | Halftone Orb | Sphere built from variable-radius dots on a hex lattice, Lambert shading, slowly circling light |
| `dot_wave` | Dot Wave | Two sinusoidal swells at different angles; dots grow on crests |
| `orbit` | Orbit | Concentric dot rings, each turning at its own slow speed and direction, one red dot on one ring |
| `gradient_dither` | Gradient Dither | Two-tone gradient quantised onto a dot lattice (Bayer 4x4, Bayer 8x8 or blue-noise-like pattern) |
| `matrix_rain` | Matrix Rain | Sparse falling dot columns with fading tails |
| `contour_map` | Contour Map | Topographic isolines drawn in dots from value-noise terrain |
| `pulse` | Pulse | Rings of dots; origin follows the last touch, speed follows battery level and charging |
| `glyph_burst` | Glyph Burst | Radial dot starfield on a log-polar grid |

The dot wallpapers share the palettes in `Palettes` (Midnight, Paper, Signal Red, Mono, Ember, Frost) so their presets feel like one family.

`FlutedBloom` (a flower seen through reeded glass) and `GrainTotem` (stacked flat shapes and sand-like grain) exist in `wallpapers/` but are not in `AllWallpapers.list` yet, so users cannot pick them.

## Rendering pipeline (`WallpaperLayer`)

`WallpaperLayer(config, animate, maxFps = 60, scroll, blurPx, dim, allowGlass)`:

1. **Resolve** the config (`remember(config)`) and create the `RuntimeShader` once per wallpaper (Android 13+). Any failure yields `null` and the Canvas path is used.
2. **Clock.** Time is a `mutableFloatStateOf` read only inside the draw lambda, so animating redraws without recomposing anything. A `withFrameNanos` loop runs under `repeatOnLifecycle(RESUMED)`, so frames stop when the launcher is not visible. Frames are skipped to honour `maxFps` (minimum interval `1e9 / maxFps - 2 ms`), and each time step is clamped to 0.1 s.
3. **When it animates**: `animate` is true, the wallpaper is `animated`, the user's speed is not Off, it is not (battery-saver pause on and battery saver active), and it is not ("only while charging" on and not charging). Otherwise it renders one static frame at `staticTime` (18 s). Battery level and charging come from the sticky `ACTION_BATTERY_CHANGED` broadcast, battery saver from `ACTION_POWER_SAVE_MODE_CHANGED`; there is no polling.
4. **Frame update.** The frame is filled (size, scroll, touch, battery, hour, colours, params, `layoutKey`) and the shader is bound and drawn with a `ShaderBrush`, or `drawFallback` runs. Failures flip the wallpaper to the fallback permanently.
5. **Photo mode.** If `config.id == "image"` and `imagePath` is set, a sampled bitmap (power-of-two `inSampleSize`, decoded off the main thread) is drawn center-cropped instead of a procedural wallpaper. Photos come from the system Photo Picker and are copied to `files/wallpapers/`.
6. **Dim.** A black rectangle at the requested alpha is drawn last.
7. **Layer effects** (`graphicsLayer.renderEffect`, Android 12+ for blur, 13+ for Glass): optional Glass, then optional blur. The blur radius is read in the layer block, so the drawer can ramp it per frame without recomposition.

Home passes `scroll` as `(currentPage + offsetFraction) / homePages` (when scroll parallax is on), `blurPx = drawerBlur * drawerProgress + homeBlur`, and `dim = homeDim + (drawerDim - homeDim) * drawerProgress`. Settings previews use `animate = false` or 24 to 30 fps. The default cap of 60 is used on the home screen. Reduce motion and the system "remove animations" setting affect UI springs, not this engine; use the wallpaper animation setting "Off".

### Animation settings

`WallpaperConfig.animation` is Off, Slow (x0.5), Normal (x1) or Fast (x2), multiplying `time`. `animateOnlyWhileCharging` and `pauseInBatterySaver` (on by default) gate frames as described above. `scrollParallax` shifts patterns with the page scroll. `parallax` (tilt strength) is stored but has no effect yet.

## Glass effect

`GlassEffect.create(width, height, stripes)` returns a `RenderEffect` wrapping an AGSL shader (`uniform shader content`) applied to the whole wallpaper layer, so it works on any wallpaper and on photos. It is Android 13+ only; on older versions the setting has no visible effect.

For each of `stripes` vertical flutes (`config.glassStripes`, clamped to 4..80, default 22):

- the flute index `i` and position `f` within it (0..1) are computed from `p.x / flute width`;
- a cylindrical-lens offset `lens = 0.5 - f` samples the content at `(i + 0.5) * w + lens * w * (1 + 1.6 * strength)`, clamped to the screen, which mirrors and compresses a slice of the image across each flute;
- a small vertical shift toward the flute centre adds depth;
- a soft highlight is added on the left of each flute and a shade on the right.

The effect is chained with blur (glass first, then blur). `allowGlass = false` turns it off for the photo thumbnail in the gallery. The `Glass` toggle and the flute count are in the wallpaper editor.

## Live wallpaper service

`DotWallpaperService` (`android.permission.BIND_WALLPAPER`, declared with `uses-feature android.software.live_wallpaper required=false`) runs the same wallpapers system-wide. The settings "Live wallpaper" row opens the system preview for it (`ACTION_CHANGE_LIVE_WALLPAPER`, falling back to the chooser).

- Config: it reads `WallpaperConfigSource.wallpaperConfig` from the application object, so settings changes apply live.
- Drawing: Choreographer plus a hardware canvas (`lockHardwareCanvas`), only while visible, at most about 30 fps (a 28 ms delay between callbacks), through the same `bindUniforms` or `drawFallback`.
- Scroll parallax uses the launcher's `xOffset` from the system.
- Not supported in the service: Glass, blur, dim, photo mode, "only while charging" and "pause in battery saver" (battery is reported as full and not charging).

## Customizer and presets

The editor (`WallpaperEditorScreen`) edits `settings.wallpaper`: preset swatches, parameter sliders, colour slots, animation, depth, Glass, blur and dim for home and drawer, and Randomize (a random preset with every parameter jittered inside its range, snapped to `step`). "Save preset" stores the `WallpaperConfig` JSON in the `wallpaper_presets` table; saved presets are included in `.dotbackup`.

## Browser preview harness

`tools/wallpaper-preview/` contains a small WebGL2 page that translates the AGSL in the Kotlin files to GLSL and renders it in a browser, so shaders can be iterated without a device. See the comment at the top of `index.html` for the query parameters. It is a development aid; the Android implementation is authoritative.
