## Transitive dependencies

The libraries above pull in further AndroidX and Kotlin artifacts (for example WorkManager through Glance, and SQLite support through Room). They are predominantly Apache License 2.0 and are not individually audited here. `./gradlew :app:dependencies` prints the full resolved graph for a given build.

## Not included

DotOS ships no Nothing Technology Limited assets: no wallpapers, icon artwork, logos or the proprietary Ndot / NType fonts. All wallpapers are generated by code in this repository, and all icon glyphs are original drawings made with the glyph DSL in `feature/icons`.
